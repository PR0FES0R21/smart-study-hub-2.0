## 🎓 **TRAINING MATERIALS**

### **For Frontend Team:**

1. **Read First:** `LMS_API_FRONTEND_GUIDE.md`
2. **Reference:** API endpoint list (Section 1-8)
3. **Study:** Complete User Flows (Line 1838)
4. **Copy-Paste:** Code examples throughout document
5. **Test:** Use Postman/Insomnia untuk test endpoints

### **Key Concepts to Understand:**

1. **References vs Embedding:**
   - Lessons are standalone
   - Modules contain lesson references
   - Courses contain module references
   - No nested data, all via references

2. **Progressive Loading:**
   - Load course → Load modules → Load lessons
   - Don't load everything at once
   - Fetch details on-demand

3. **Progress Tracking:**
   - Page-level tracking
   - Component-level tracking
   - Auto-aggregation to lesson/module/course
   - Real-time updates

4. **Media & Components:**
   - Upload files → Get URLs → Create references
   - Use `{{media_key}}` in markdown
   - Components defined in page data
